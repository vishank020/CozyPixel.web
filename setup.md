# 🛠️ Tech Stack & Setup Guide

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com) (Recommended)

---

## 🚀 Getting Started

To run this gallery locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/cozypixels-web.git
cd cozypixels-web
```

### 2. Install dependencies
```bash
pnpm install
```

### 3. Generate the Manifest
The site relies on a JSON manifest generated by crawling the original GitHub repository. Run this script to fetch the latest wallpapers:
```bash
pnpm run generate-manifest
```
*Note: If you hit GitHub API rate limits, set `GITHUB_TOKEN=your_token pnpm run generate-manifest`.*

### 4. Start the development server
```bash
pnpm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the gallery.
